## 2. GenAI の基礎知識

| キーワード                     | 概要                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| **生成  AI (Generative AI)**   | テキスト・画像・コードなどを「生成」する AI。確率的に次のトークン（単語・記号）を予測する。 |
| **LLM (Large Language Model)** | 大規模テキストを事前学習したモデル。ChatGPT はその一種。                                    |
| **Transformer**                | 2017  年発表。自己注意機構 (self‑attention) で長文の文脈を保持。                            |

> **ポイント** : ChatGPT は “答えを検索” しているのではなく、**最もらしい続きを予測** しているだけ。必ず **事実確認 (Fact‑Check)** を！

### 言語モデリング（Next‑Token Prediction）

> **タスク** : 途中で切れた文章の続きを当てる

```
被害者の最後の言葉: 「犯人は・・」
```

容疑者は **太郎／花子／一郎** の 3  名。

```
容疑者は 太郎・花子・一郎 の誰かだ。
調査の結果、太郎 と 一郎 にはアリバイがあった。犯人は・・
```

LLM は文脈から **「花子」** を予測します。

## 4. 生成 AI の使い方

色々な効率よく使う方法はありますが、まずは使って慣れてください。使っていると気づくと思いますが、１００点はなかなか出てこないです。Google での検索と同じようにどの答えが正しいかは自分で判断する必要があります。なので、生成 AI を使いこなせるかは使う人次第なのです。使う人が質の担保をする必要があります。生成 AI を使うことで確実にアウトプットを出すスピードは上がりますが、質は人次第です。また、同じ Chat 内では履歴が引き継がれますので意識しながら使ってください。

### 利用上の注意

1. **ファクトチェック** : 重要な数値や引用は必ず裏どり
2. **具体的プロンプト** : 曖昧な指示は品質低下
3. **機密データ管理** : 社外共有範囲を超えるデータは貼り付け禁止

## 6. プロンプトの書き方

**プロンプトとは？**
「プロンプト」とは、簡単に言えば AI（人工知能）に対する指示や問いかけのことです。ChatGPT のような AI に「何をしてほしいか」を伝えるために使います。

### 6‑1. なぜ重要か

- **具体性 = 品質** — 曖昧な指示は曖昧な結果につながる
- **再現性** — 良いプロンプトはコピペで再利用できる
- **セキュリティ** — 指示にガードレールを組み込める

### 6‑2. 4 パートテンプレート `Role｜Context｜Task｜Format`

| パート      | 目的               | ベストプラクティス                   | NG 例                |
| ----------- | ------------------ | ------------------------------------ | -------------------- |
| **Role**    | モデルの視点を固定 | 「あなたは**医療 CS リーダー**です」 | 「プロっぽく」       |
| **Context** | 前提・素材を提供   | 箇条書きで要点、機密はマスク         | 「詳細は割愛」       |
| **Task**    | 作業指示           | 動詞＋成果物＋評価基準               | 「いい感じに」       |
| **Format**  | 出力構造を固定     | *文書型*＋貼付けやすい形＋数値制約   | 曖昧な「箇条書きで」 |

> **例**\
> `Role: シニアPM｜Context: プロジェクト概要…｜Task: リスクを3件抽出し優先度順に並べる｜Format: Notionの決まったテンプレなど (列: リスク, 影響度, 対策)`

### 6‑3. 追加テクニック（概要）

| テクニック名                                | 目的（何のため？）           | コツ（どう使う？）                                                                              |
| ------------------------------------------- | ---------------------------- | ----------------------------------------------------------------------------------------------- |
| **制約条件の明示**                          | 出力の再現性・安定性を高める | 数値（例：100 文字以内）、トーン（例：丁寧語）、形式（例：表形式で）を具体的に指示する          |
| **例（Few-Shot）**                          | 出力のパターンを学習させる   | 入力と出力の例をセットで見せることで「こう返せばいいのか」を AI に理解させる                    |
| **思考の連鎖（Chain-of-Thought）**          | 論理的な推論の精度を上げる   | 「ステップ・バイ・ステップで考えてください」「理由も説明してください」と明記する                |
| **自己批評モード（Self-Critique）**         | 自動的なブラッシュアップ     | 「まず下書きを作ってください → 次に、自分で評価し改善してください」という 2 段階で指示する      |
| **区切り記号使用**                          | 長文や複雑な構造を整理する   | テキストやコードを ```や《》などで囲んで、AI が情報の境界を認識しやすくする                     |
| **システムメッセージ**                      | ふるまいを強くコントロール   | 「あなたは礼儀正しい日本語教師です」など、ロール（役割）を明確に定義し、system プロンプトに設定 |
| **温度制御（temperature）**                 | 創造性や一貫性を調整する     | 値を低く（例：0.2）→ 一貫性重視、高く（例：0.8）→ 創造性・多様性重視                            |
| **反復型プロンプト（Iterative Prompting）** | 複雑な課題を分けて処理する   | 一気に聞かず、「まず概要だけ教えて → 次に詳細 → さらに具体例」と段階的に深掘りする              |

###　反復型プロンプト（Iterative Prompting）

> **ケース：商品 LP（ランディングページ）作成を段階的にブラッシュアップ**

```text
[ターン1] Q: 新製品「EcoBottle」のLPアウトライン（見出し 5 つ）を作成してください。
[ターン1] A: H1: 製品紹介… H2: 特長… H3: 仕様… H4: 口コミ… H5: 購入方法…

[ターン2] Q: H2「特長」を 150 字以内の箇条書き 4 点で詳細化してください。
[ターン2] A: • 100% リサイクル素材… • 軽量設計… …

[ターン3] Q: 今の H2 にユーザー事例 1 つを追加し、説得力を高めてください。
[ターン3] A: • 導入企業 ABC 社で年間 30% のペットボトル削減に成功…
```

このように「① アウトライン → ② 章単位で肉付け → ③ 証拠追加」のように段階的に指示を重ねるのが Iterative Prompting です。
